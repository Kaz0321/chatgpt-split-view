# タブ操作・名前付きグループ改善版の適用

このZIPは未リリースの動作確認用です。manifestの表示バージョンは0.9.3です。GitHub mainや普段使うChromeには自動反映されません。

## 今の拡張を更新する

1. 未送信の重要な入力を別に控えます。更新・再読み込みで添付や生成途中の状態は戻せません。
2. Chromeで `chrome://extensions/` を開き、現在の「ChatGPT Split View」の読み込み元フォルダーを確認します。
3. 現在の読み込み元フォルダーを別の場所へコピーし、旧コードを保管します。拡張はアンインストールしません。
4. 改善版ZIPを別フォルダーへ展開します。直下に `manifest.json` がある配布用ZIPです。
5. 展開した15個の実行ファイル（下記）を、**現在の読み込み元フォルダー**へ上書きします。ソースcheckoutから読み込んでいる場合は、その `extension/` フォルダーです。保存データやChromeプロファイルは操作しません。
6. 拡張機能管理画面で、この拡張の再読み込みボタンを押します。
7. ChatGPTの対象ページを再読み込みします。

実行ファイル: `manifest.json`, `background.js`, `windows.js`, `detached.js`, `persistence.js`, `core.js`, `content-layout.js`, `drafts.js`, `workspace.js`, `options.html`, `options.css`, `options.js`, `popup.html`, `popup.css`, `popup.js`。

読み込み元フォルダーを変えて新規登録すると拡張IDや保存領域が変わる場合があります。既存の作業を引き継ぐ更新では、同じフォルダー・同じ拡張を使います。ストア管理など読み込み元を更新できない方式の場合は、この方法で置き換えず、インストール方式を確認してください。

## 反映を確かめる

1. メニューに「タブ一覧」と「名前を付けて保存」があり、「下書きを比較」「新しい作業を開始」がないことを確認します。バージョン番号だけでは判別できません。
2. ダミー入力のある列で `_` を押し、背表紙の `□` とタブ一覧の「復元」で戻します。元の入力・幅が残ることを確認します。
3. 表示中・折りたたみ中・退避中の列が一覧に並ぶことを確認します。
4. テスト用の名前を付けて保存します。同名で再保存すると「(2)」になり、現在の列が変わらないことを確認します。
5. 保存後にダミー入力を変え、保存済みグループ一覧から元のグループを選びます。確認画面で続行しても現在の入力が残り、同じ会話は既存の列を再利用し、不足する列だけ追加されることを確認します。同じグループをもう一度復元しても列数が増えないことを確認します。
6. 復元確認でキャンセルした場合は元の列・入力がそのまま残ることを確認します。

確認画面が閉じない、未保存が表示されるなどの問題が出た場合は入力を控え、切り替えを繰り返さず状況を確認してください。

## 旧コードへ戻す

保管した旧実行ファイルを同じ読み込み元フォルダーへ戻し、拡張と対象ページを再読み込みします。今回追加した名前付きグループは旧コードの一覧には表示されませんが、保存領域から削除していません。
