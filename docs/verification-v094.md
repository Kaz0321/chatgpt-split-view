# v0.9.4 操作バー重なり

ユーザー画像で左一覧非表示の浮動バーが1列目上端へ重なり、元画面のChat/Workヘッダーが上部に露出していた。旧保存座標を使うバーと、上48pxを予約する会話列の位置が一致していなかった。

左一覧非表示時は全幅・上端0・高さ48pxにバーを固定。会話列はtop48pxで隣接する。旧保存座標は削除しない。元画面の単独復帰ボタンは変更しない。

ローカルUI実測：1280×720でoverlay=[0,0,1280,48]、board=[0,48,1280,720]。実際のスクリーンショットでも重なりと元ヘッダー露出がない。自動試験226件成功、360/900/1844pxの幅と旧座標48,50を含む。既存入力の往復保持試験も成功。

実Chromeの再読み込み・認証済み画面での最終確認は未実施。提示画像は実見したが、修正後の実環境確認とは区別する。
