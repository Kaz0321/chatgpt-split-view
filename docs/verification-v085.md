# v0.8.5 verification

The removed warning was the extension's own `confirm` in `closePane`. Close still removes the iframe, disposes observers/listeners/draft recovery and drops references; closed history stores metadata only. Reload's separate confirmation remains. No ChatGPT beforeunload handlers or browser security warnings are intercepted or disabled.

Persistence uses existing storage permission: chrome.storage.local per workspace, chrome.storage.session for current tab ownership and writer tokens. Service-worker writes/claims are serialized; document tokens reject writes after a reload, sequences reject old writes, and duplicate tabs fork IDs. Startup waits for durable reads and suppresses saves until restoration finishes. Session storage remains a fast fallback. When session identity is absent, startup automatically claims the newest unclaimed workspace for the same host (origin and hostId), preferring the same page. A fresh home page can restore a previous conversation-page workspace. Other hosts and already-claimed workspaces are excluded. The floating list remains an alternative explicit restore route.

Node tests cover fresh browser-session storage with local data retained, pane order/selection/parked state/width/drafts/closed metadata, duplicate tabs, worker restart, delayed and stale writes, write failure preservation, ownership release and duplicate initialization. Existing lifecycle tests verify warning-free destruction and fresh-frame history restoration.

Edge synthetic fixture: created 3 panes; closed one without a dialog and observed iframe count 3 to 2. Parked another, typed a synthetic draft and set width480. Reload restored draft and state. Closed the QA browser tab and restarted the persistence process (disk retained, session owners cleared); opened a fresh browser tab and first verified explicit restoration. Repeated the close/process restart/new-tab cycle after automatic restore was added: the workspace and draft appeared without menu interaction. It recovered width480, draft, one parked pane and one closed-history entry. Restoring the closed entry produced a new iframe with no draft. This exercised production persistence/workspace code via local Chrome-storage/origin adapters.

Limit: all user Edge windows were not shut down, and the installed extension was not updated. Full browser-process shutdown/relaunch with the installed extension remains unverified. The test instead used an actual tab close/new tab plus persistence-process restart and automated fresh-session tests. Attachments, generation state, hard-kill before an asynchronous write completes and OS memory reclamation amount are not guaranteed.
