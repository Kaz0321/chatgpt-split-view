# ChatGPT Split View

### v0.8.9 保存・復元の保護

下書きが競合した場合は、現在の入力と保存済み下書きを両方保持し、設定メニューで比較・コピー用の選択・明示的な破棄ができます。未保存時は再試行ボタンを表示し、最新状態を保持します。別の作業へ切り替える前に現在の保存成功を確認します。

列を閉じる際の警告はありません。iframeを即時破棄し、直前の1列は30秒以内ならテキストを元に戻せます（ページを離れると元に戻す情報は失われます）。添付・生成中状態は復元できません。自動復元時には通知と「新しい作業」への入口を表示します。

### v0.8.8 同じ会話の重複防止

同じ会話を選ぶと既存の列へ移動し、退避中なら復元します。URL表記の違いと履歴からの再開にも対応。保存済みの重複列は復元時に統合し、異なる下書きは別の新規会話に保持します。

### v0.8.7 埋込みの背景帯

一覧を隠しても残っていた52pxの背景・影レイヤーを除去しました。本文背景と親画面は維持します。

### v0.8.6 埋込み内の左境界

埋込み内の一覧を隠したとき、本文左端に残る境界線を除去しました。親画面と列間の区切りは維持します。

### v0.8.5 ブラウザ終了後の復元

×は確認なしで列のiframeを破棄します。閉じた履歴はURL・表示名・幅などの情報だけを保持し、再読み込みで復元します。

開いている列のURL・順序・選択・幅・退避状態・対応入力欄の未送信テキストと設定を、操作時に拡張のローカル領域へ保存します。拡張の起動時に終了前の作業を自動復元します。元のタブ情報がない場合も、同じホストの保存済み作業を自動で選びます。同じページを優先し、別タブが使用中の作業は重複して開きません。別の作業はメニューの「保存した作業を復元」から選べます。保存失敗は画面に表示します。添付ファイル・生成中の処理・ページ内の実行状態は復元対象外です。以下の旧版記述より本節を優先します。

### v0.8.4 操作ボタンの配置

フローティングのメニュー右に「新しいチャット」と「左一覧を隠す／表示」を配置しました。メニューを展開せず操作できます。本文左右余白は「その他の設定」で変更・保存・リセットできます。退避中一覧は引き続きメニュー内に直接表示します。

### v0.8.3 左一覧の表示切替

左一覧の既定幅とリセット値は348pxです。現在のChatGPT左UIの340pxと右端の8px操作領域を確保し、狭くした場合は一覧内をスクロールできます。保存済みの幅は維持します。「左一覧を隠す」で左幅を0pxにし、フローティングの「左一覧を表示」で以前の幅とロック状態へ戻します。非表示状態も再読み込み後に復元します。

### v0.8.2 幅の調整

列の既定幅はChatGPT本来の本文最大幅から自動計算します。「全列幅」のリセットで全列をこの既定幅に戻します。本文の左右余白上限は0〜12pxで変更できます。左一覧は境界のドラッグ、または設定フローティングの数値で180〜520pxに調整でき、リセットは276pxです。ロック中はドラッグ・矢印キー・フローティングからの幅変更を止めます。幅とロック状態は再読み込み後も復元します。

ChatGPTの複数の会話を横並びで使える、非公式のChrome拡張機能です。履歴を見ながら、列幅の調整・等分・ドラッグでの並べ替えができます。

## インストール・更新

1. このリポジトリのソースZIPをダウンロードして展開します。
2. Chromeの拡張機能管理画面で「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から、展開したリポジトリ内の **`extension/` フォルダー**を選びます。
   - 配布用の `chatgpt-split-view-v0.8.9-candidate.zip` を使う場合は、展開後の **`manifest.json` があるフォルダー**を選んでください。
4. ChatGPTを開き、ページ内の **「分割を開始」** を押します。

更新時は、読み込み元のファイルを新版へ置き換え、拡張機能管理画面で拡張を再読み込みします。未送信の内容を控えてから、ChatGPTのページも再読み込みしてください。

## 使い方

- **「メニュー」**：新しいチャット、列幅、等分、退避一覧・閉じた履歴検索・本文余白、その他の設定。
- **「元画面」／「分割へ」**：元のChatGPT画面と分割表示をワンボタンで切り替えます。
- **「新しいチャット」**：分割中は、新しい会話を右端に追加します。履歴から会話を選んでも追加できます。
- **列の `⠿`**：ドラッグで並べ替え。選択して `Alt＋←／→` でも移動できます。
- **列の「更新」／「_」／「×」**：再読み込み／一時退避／列を閉じる操作です。退避はiframeをその場で保持し、設定フローティング内の退避一覧から元の位置・幅へ直接復元します。閉じるとiframeを破棄します。直前の列の未送信テキストは30秒以内なら元に戻せます。ChatGPTの保存済み会話自体は削除しません。
- **操作ボタンの `⠿`**：邪魔なときはドラッグで移動できます。ブラウザーの拡張アイコンからもメニューを開けます。

列幅は外枠の幅です。広い列では元の本文の最大幅に合わせ、狭い列では折り返します。画面構造を検出できない場合は余白を変更しません。列が画面に収まらない場合は横スクロールしてください。

### v0.8.0 の設定と履歴

本文の左右余白上限は0〜12px（既定12px）。列幅と独立して保存・リセットできます。元の余白が小さければ広げません。閉じた履歴はこのワークスペースのタイトル・URLを検索し、再読み込みで復元します。全ChatGPT会話検索ではありません。閉じた履歴は最大200件のmetadataのみを保存します。開いている列・退避中の列の未送信テキストは拡張のローカル保存とタブのsessionStorageに保存し、ページ再読み込み・ブラウザ再起動後に復元します。退避中のiframeは同一ページ内で保持します。ページを再読み込みした場合は保存状態から再生成します。添付ファイル・生成中の処理・即時のメモリ解放量は保証しません。復元は保存成功した同じブラウザプロファイル内が対象で、端末間同期は保証しません。

### v0.8.1 再読み込み復元

設定画面の退避一覧はタイトルと「戻す」を直接表示します。余白説明と末尾の注意書きは削除しました。タブURL・名前・順序・幅・表示/退避・閉じた履歴・設定・ワークスペース識別子を同じブラウザタブに保存します。旧版の保存形式も読み込みます。

対応する入力欄（prompt-textarea、または一意のProseMirror textbox）の未送信プレーンテキストは入力時とページ離脱時に保存します。既存の入力は上書きしません。保存済みテキストは設定メニューから確認できます。閉じる（×）は下書きを捨ててiframeを破棄し、閉じた履歴には下書きを含めません。保存領域不足などで保存できなかった場合は操作中にエラーを表示します。

## v0.8.10: 別ウィンドウと背表紙

列の ↗（新規ウィンドウ）は送信済み会話を別ウィンドウで開き、成功後に元の列を退避します。分離先の「タブに統合」で元の列を選択・復元します。下書き・添付・生成状態は移行せず、分離先は内容確認のため自動では閉じません。元画面を閉じた場合は「元の作業を開く」で保存済み作業を開いてから統合します。ブラウザの起動設定は変更しません。

列の左端をクリックすると、タイトルバーと同じ32px幅の背表紙になります。タイトルは左へ90度回転し、再クリックまたはEnter/Spaceで戻ります。元の幅と折りたたみ状態は保存します。退避とは別機能で、iframeは保持するためメモリ削減は保証しません。
