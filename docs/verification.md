## 実 Chromium の合成画面

初期 v0.5 の15グループは14 PASS と、子 head 交換直後のナビ一時表示の観測1件。最終版の再試験は次の8グループすべて PASS でした。

## 残る確認と制約

- 検証環境の管理ポリシーにより実拡張を読み込めず、本物の action popup／MV3 通信を実機確認できていません。別ルートで回避していません。
- ChatGPT は未ログインだったため、保存済み会話・認証・Project/GPT/local 会話・生成中操作・実添付・端末間同期は未検証です。
- 実サイトの親 sidebar に対する修正効果は未確定です。親祖先の非表示や今後の DOM 変更には追加対応が必要になり得ます。
- 子 head 全交換などで stylesheet 読込中に汎用ナビが一時表示する場合があり、ちらつきゼロではありません。
- CSS order と DOM／Tab 順が一致しない場合があります。×は文書を保持し、メモリを即解放しません。
- 最小幅320pxにより多列は横スクロールします。200列までの保存正規化があるため、無制限ではありません。

正式受入は、ポリシー上許可されたログイン済み検証環境で、popup開始／終了、親固定／狭幅／復旧、対象更新、10会話、実ファイルの投入先を確認してから判断してください。
