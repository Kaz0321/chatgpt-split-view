Node.js 24.22.1 で69件合格。内訳は v0.4 からの46件、popup14件、v0.5 のメッセージ認可／右端追加／更新／親sidebar／UI8件、画面外 iframe の stylesheet 回帰1件です。VM・模擬 DOM・模擬 Chrome API を使用するテストを含みます。

## 実 Chromium の合成画面

候補の workspace／popup UI を、実会話を使わない同一originの合成アプリで操作しました。Core の URL 判定先と Chrome API を adapter に置き換えています。拡張のインストールや ChatGPT 埋め込みを行った検証ではありません。合成サイトのアカウント情報・配備用 metadata・生の QA 画面／ログはこのリポジトリに含めません。

初期 v0.5 の15グループは14 PASS と、子 head 交換直後のナビ一時表示の観測1件。最終版の再試験は次の8グループすべて PASS でした。

| 再試験 | 観測 |
|---|---|
| 10列／上段 UI | 10個の独立iframe、初期load10、上段toolbar0 |
| popup幅／等分 | 768px×10→320px×10、instanceと下書き保持 |
| 幅850px／親DOM再生成 | 親表示維持、再挿入後11msで復帰。650msの欠落時間は除外 |
| 幅530px／子head再生成 | 親幅210pxで重なりなし。全10子ナビが再び非表示 |
| ネイティブ並べ替え | 10番目→8番目、全instanceと下書き保持 |
| OSファイルDnD | 並べ替え後の対象だけダミーファイル受領1、他9列0 |
| 更新取消 | 対象の下書き・ダミー添付・instance保持 |
| 更新承認 | 対象だけ新instance、他9列不変 |

10列は4種類の架空経路を繰り返した独立文書です。実会話10件の性能ベンチマークではありません。ファイルは合成 drop target で名前・サイズの受領を確認しただけで、サーバー送信はしていません。

## 残る確認と制約

- 検証環境の管理ポリシーにより実拡張を読み込めず、本物の action popup／MV3 通信を実機確認できていません。別ルートで回避していません。
- ChatGPT は未ログインだったため、保存済み会話・認証・Project/GPT/local 会話・生成中操作・実添付・端末間同期は未検証です。
- 実サイトの親 sidebar に対する修正効果は未確定です。親祖先の非表示や今後の DOM 変更には追加対応が必要になり得ます。
- 子 head 全交換などで stylesheet 読込中に汎用ナビが一時表示する場合があり、ちらつきゼロではありません。
- CSS order と DOM／Tab 順が一致しない場合があります。❌は文書を保持し、メモリを即解放しません。
- 最小幅320pxにより多列は横スクロールします。200列までの保存正規化があるため、無制限ではありません。

正式受入は、ポリシー上許可されたログイン済み検証環境で、popup開始／終了、親固定／狭幅／復旧、対象更新、10会話、実ファイルの投入先を確認してから判断してください。
