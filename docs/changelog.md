# v0.9.0（2026-11-07）

- 左列一体型メニューと38pxのコンパクトなタブ行。状態文字は画面上から除き、ボタンと読み上げで状態を提供。
- グループ保存専用ボタンから名前入力を表示。当日の日付を初期値とし、キャンセルは無変更。
- 元画面の操作バーも左上へ統一。設定済みの幅と既存データを保持。
- GPT開始ページへの汎用対応と会話との重複判定の分離。

- 同じ会話の列を追加・履歴・復元経路で再利用。名前付きグループも既存ページと入力を保持して不足分のみ追加。新規未送信チャットは列IDで区別し、ダブルクリックによる二重作成を防止。

- `_` で折りたたみ、背表紙上部の `□` で復元。退避専用ボタンは撤去し折りたたみに統一。旧退避データは復元可能。
- メニューに全タブと表示・折りたたみ・退避・選択・休止の状態を表示。
- 自動復元の常設ボタンをメニュー内の閉じられる通知へ変更。
- 下書き比較UIを撤去（データは保持）。新しい作業開始UIを名前付きタブグループ保存に置換。保存済みグループと旧作業を一覧から復元。同名は連番、グループ復元は既存列を保持して不足分を追加し、保存元は変更しない。
- その他の設定の履歴クリック説明を、右端追加・既存列の再利用という実装に合わせて修正。
- READMEを利用手順中心に整理。過去のREADME全文は [旧README・更新履歴](readme-history.md) に保全。

# 変更履歴

## v0.9.3（2026-11-07）

- 復帰ボタンが親ヘッダーのpointer-events:noneを継承し、表示されてもクリックできない不具合を修正。ボタンとホストでpointer-events:autoを明示。
- ヘッダー不在時は復帰ボタンを本文末尾でなく先頭に配置し、スクロール中も上端に保持。画面外・非表示のヘッダーを除外。
- ポインター無効のヘッダーとヘッダー不在のUI検証条件を追加。

## v0.9.2（2026-11-07）

- v0.9.1の外枠が重なり順を作り、分割メニューがネイティブサイドバーの背後に隠れる不具合を修正。外枠はdisplay:contentsとし、レイアウト枠も重なり順も作らない。
- 元画面の復帰ボタンを同じShadowRootへ繰り返し移動しないよう修正。
- ネイティブ側の高いz-index、モード復帰、狭幅、リロードを確認できるローカルUI検証用ビルダーを追加。

## v0.9.1（2026-11-07）

- 元画面では分割復帰ボタンのみを通常フローに配置し、固定操作バーを非表示。
- 拡張ホストをゼロサイズ固定要素にして、元画面のレイアウトへの寄与を除去。
- ページやiframeの高さ・入力内容を変更せず分割へ復帰。

## 0.7.1 — 純正の操作メニューとの共存

- 純正のメニュー／メニュー項目からのクリックを、履歴リンク・新規チャットの横取り対象から除外。親画面と同一originの子画面で適用。
- 開いている純正メニューと既知のRadix配置ラッパーを前面化。サイドバー内にあるメニューは祖先経路だけクリップを一時解除し、閉じる／元画面への切替で追加属性とCSSを撤去。
- 元のinline style、会話データ、権限、通信先、保存形式は変更なし。実サイトの全メニュー構造への適合は未確認。

## 0.7.0 — 本文幅と余白の調整

- 本文の最大幅と列の外枠幅を区別し、検出できた会話ではpadding・枠線・scrollbarを考慮して外枠上限を算出。
- 会話の外側ラッパーの左右余白を最大12pxに縮めつつ、元の本文最大幅を維持。狭い列は自然に折り返す。
- 未検出の画面は余白を変更せず、その状態をメニューに表示。既存manual／equal設定と保存キーを維持。
- 寸法の再測定を集約し、iframeや下書きを再生成しない。権限・通信先の追加なし。
