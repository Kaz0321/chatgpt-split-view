# 変更履歴

## 0.7.1 — 純正の操作メニューとの共存

- 純正のメニュー／メニュー項目からのクリックを、履歴リンク・新規チャットの横取り対象から除外。親画面と同一originの子画面で適用。
- 開いている純正メニューと既知のRadix配置ラッパーを前面化。サイドバー内にあるメニューは祖先経路だけクリップを一時解除し、閉じる／元画面への切替で追加属性とCSSを撤去。
- 元のinline style、会話データ、権限、通信先、保存形式は変更なし。実サイトの全メニュー構造への適合は未確認。

## 0.7.0 — 本文幅と余白の調整

- 本文の最大幅と列の外枠幅を区別し、検出できた会話ではpadding・枠線・scrollbarを考慮して外枠上限を算出。
- 会話の外側ラッパーの左右余白を最大12pxに縮めつつ、元の本文最大幅を維持。狭い列は自然に折り返す。
- 未検出の画面は余白を変更せず、その状態をメニューに表示。既存manual／equal設定と保存キーを維持。
- 寸法の再測定を集約し、iframeや下書きを再生成しない。権限・通信先の追加なし。

## 0.6.0 — アプリモード向けページ内操作

- 移動可能な小型オーバーレイからメニューを呼出。ブラウザーの拡張メニューに依存せず列幅・等分・復帰・設定を操作。
- 元画面／分割の1クリック切替。既存iframeは破棄せず、元画面では親固定と履歴／新規クリックの介入を停止。
- 拡張のパネル・通知・並べ替え目印の影を削除し、枠線／非対話の移動目印を使用。
- 標準の新規チャットリンクとボタンを右端の独立新規iframeへ割当。未保存URLの重複を許可し、保存済み経路への移行時は文書を保持してURLだけ更新。
- 同じ保存キーを維持。sessionには新規会話フラグ、選択位置、操作ボタン座標を追加。権限追加なし。


## 0.5.1 — 列ヘッダーの整列

- 閉じるの色付き絵文字をモノクロの × に変更。更新・移動・閉じるを高さ24px、同じ余白・角丸・ホバー状態へ統一。
- 移動つまみも24px幅とし、タイトル入力の高さを揃えた。ヘッダー高さ32pxと会話表示領域は維持。
- 閉じる/列名のアクセシブルなラベルを明示。読み込み・並べ替え・下書き保持ロジック、保存キー/権限は変更なし。


## 0.5.0 候補 2026-10-25

- 常設の上段 UI を撤去し、拡張 action popup に開始／終了・幅・等分・列追加／復帰を移動。
- 会話は常に右端へ追加。列に個別更新と右端❌を配置し、曖昧な挿入ボタンを撤去。
- 更新は毎回確認し、対象 iframe だけを再読み込み。独自同期機能は追加していない。
- 親 sidebar の可逆固定と狭幅対応。DOM 変化に応じた再検査に変更し、周期的な再展開待ちを廃止。
- 子 stylesheet の読込後に即時再検査を追加。子ナビの一時表示を完全に排除したわけではない。
- Node 69件。実拡張／ログイン済み ChatGPT の E2E は未検証。

## 0.4.0 候補 2026-10-25

## 公開用整備

公開名を ChatGPT Split View、リポジトリ名を chatgpt-split-view とし、manifest の表示名3項目だけ変更。v0.5.0 の動作コードは維持し、69件の Node テストのURL・表示名例を一部明らかな架空値に置換したうえで、公開向け文書、依存不要の検査／ZIP生成スクリプト、最小 CI を追加。古い UI を前提にした Python ブラウザーテスト、公開合成サイト資材、内部 QA ログ・画面は含めていません。
