# ChatGPT Split View

ChatGPTの複数の会話を横並びで使える、非公式のChrome拡張機能です。履歴を見ながら、列幅の調整・等分・ドラッグでの並べ替えができます。

## インストール・更新

1. このリポジトリのソースZIPをダウンロードして展開します。
2. Chromeの拡張機能管理画面で「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」から、展開したリポジトリ内の **`extension/` フォルダー**を選びます。
   - 配布用の `chatgpt-split-view-v0.8.0-candidate.zip` を使う場合は、展開後の **`manifest.json` があるフォルダー**を選んでください。
4. ChatGPTを開き、ページ内の **「分割を開始」** を押します。

更新時は、読み込み元のファイルを新版へ置き換え、拡張機能管理画面で拡張を再読み込みします。未送信の内容を控えてから、ChatGPTのページも再読み込みしてください。

## 使い方

- **「メニュー」**：新しいチャット、列幅、等分、退避一覧・閉じた履歴検索・本文余白、その他の設定。
- **「元画面」／「分割へ」**：元のChatGPT画面と分割表示をワンボタンで切り替えます。
- **「新しいチャット」**：分割中は、新しい会話を右端に追加します。履歴から会話を選んでも追加できます。
- **列の `⠿`**：ドラッグで並べ替え。選択して `Alt＋←／→` でも移動できます。
- **列の「更新」／「_」／「×」**：再読み込み／一時退避／列を閉じる操作です。退避はiframeをその場で保持し、設定フローティングの「退避中」から元の位置・幅へ復元します。閉じるとiframeを破棄し、未送信入力は失われます。ChatGPTの保存済み会話自体は削除しません。
- **操作ボタンの `⠿`**：邪魔なときはドラッグで移動できます。ブラウザーの拡張アイコンからもメニューを開けます。

列幅は外枠の幅です。広い列では元の本文の最大幅に合わせ、狭い列では折り返します。画面構造を検出できない場合は余白を変更しません。列が画面に収まらない場合は横スクロールしてください。

## 注意・免責事項

- **試験提供版です。** 実ChatGPTでの総合動作確認は未完了で、動作やデータ保持は保証しません。
- OpenAIの公式製品ではありません。ChatGPTの仕様変更により使えなくなる場合があります。
- 列やページの再読み込み・終了で、未送信の入力や添付を失う場合があります。大切な内容は先に控えてください。
- 更新ボタンは会話を読み直す操作で、端末間の同期を保証するものではありません。

### v0.8.0 の設定と履歴

本文の左右余白上限は0〜12px（既定12px）。列幅と独立して保存・リセットできます。元の余白が小さければ広げません。閉じた履歴はこのワークスペースのタイトル・URLを検索し、再読み込みで復元します。全ChatGPT会話検索ではありません。履歴は最大200件のmetadataのみを同じタブのsessionStorageに保存し、下書きは保存しません。退避は同一ページ内のみ保持され、再起動後の下書き保持や即時のメモリ解放量は保証しません。
