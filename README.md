# ChatGPT Split View

ChatGPTの複数の会話を横に並べて使うChrome拡張です。列（この拡張内のタブ）の幅変更、並べ替え、折りたたみ、作業の保存・復元ができます。OpenAIの公式製品ではありません。

## インストール・更新

1. リポジトリのソースZIPをダウンロードして展開します。
2. Chromeの拡張機能管理画面で「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で **`extension/`** を選びます。配布用candidate ZIPの場合は、展開後の `manifest.json` があるフォルダーを選びます。
4. ChatGPTを開き、画面上の「分割を開始」を押します。

更新時は読み込み元フォルダーを更新し、拡張機能管理画面で再読み込みします。未送信の内容を控えてから、ChatGPTも再読み込みしてください。別フォルダーで読み込むと拡張IDや保存領域が変わる場合があります。

## 普段の操作

- **＋ 新しいチャット**：右端に新しい会話を追加します。履歴から会話を選んでも開けます。同じ会話があれば既存の列へ移動し、退避・折りたたみ中なら復元します。
- **元画面／分割へ**：元のChatGPT画面と分割表示を切り替えます。列は保持されます。
- **列の `_`**：32px幅の背表紙に折りたたみます。元の幅、ページ、入力を保持します。
- **背表紙上部の `□`**：元の幅へ復元します。左端／背表紙のクリックでも折りたたみ・復元できます。ボタンはTabで選び、EnterまたはSpaceで操作できます。
- **×**：列のページを破棄して閉じます。ChatGPTの会話自体は削除しません。直後の「閉じた列を元に戻す」で30秒以内ならテキストも戻せます。
- **↻ 更新**：その列だけ再読み込みします。添付や生成中の状態を失う可能性があるため確認が出ます。
- **↗**：送信済み会話を別ウィンドウで開き、成功後に元の列を折りたたみます。別ウィンドウの「タブに統合」で戻せます。入力・添付・生成状態は移しません。内容確認用に別ウィンドウは自動で閉じません。
- **⠿**：列をドラッグして並べ替えます。列の操作にフォーカスがある状態のAlt＋左右でも移動できます。メニューの⠿は操作パネルの位置を移動します。

## メニューとタブ一覧

**タブ一覧** は、この作業に登録したすべての列を表示します。Chrome全体のタブ一覧やChatGPT全会話の一覧ではありません。閉じた列は「閉じた履歴」に分かれます。

| 状態・操作 | 意味 |
| --- | --- |
| 表示中／選択 | 通常幅で表示。選択でその列へ移動 |
| 折りたたみ中／復元 | 背表紙で表示。復元で通常幅へ |
| 退避中／復元 | 非表示。復元で通常幅で再表示 |
| 選択中 | 現在操作対象の列 |
| 分割表示休止中 | 元画面を表示中。「分割へ」で一覧の操作が有効になる |

一覧の `_` からも折りたためます。これらは配置の状態であり、AIの生成中・完了や同期状態ではありません。

一覧より上の「URLから追加」は会話URLを直接開くとき、「列を等分」は画面幅に合わせて並べるときに使います。「全列幅」は一括指定、リセットはChatGPT本文から測った標準幅へ戻す操作です。「左一覧幅」とロックは履歴欄の幅調整と誤操作防止に使います。列が収まらないときは横スクロールできます。

### 一覧より下の機能を使う場面

名前付きグループの復元は**追加方式**です。保存と復元は次のように異なります。

| 操作 | 現在のタブ | 保存済みグループ |
| --- | --- | --- |
| 名前を付けて保存 | 変更しない | 現在の構成・対応する入力を新しい記録として保存。同名も上書きしない |
| 名前付きグループを復元 | 既存の会話・入力を残し、不足する列だけ追加 | 元の記録は変更しない |
| 「以前の作業」を復元 | 現在の作業を保存してから、旧形式の作業全体へ切り替える | 従来の作業切り替え。名前付きグループの追加復元とは別 |

| 機能 | 使う場面・注意 |
| --- | --- |
| 閉じた履歴 | この作業で閉じた会話を再び開く。URL・表示名から再読み込みするため、未送信入力は戻らない |
| 名前を付けて保存 | タブグループ名を入力して現在の構成をコピー保存する。現在のタブは変わらない。同名は「(2)」など連番を付けて別保存 |
| 保存済みタブグループを表示 | 名前・タブ数・日時の一覧から復元対象を選ぶ。現在の作業を保存してから復元する。名前付きグループは既存の列を再利用し、不足分だけ追加するため保存元は変わらない。旧データは「以前の作業」と表示 |
| その他の設定 | 本文余白、左一覧、履歴クリック、埋め込み内ナビなど、普段変更しない設定を調整する |
| 設定JSONの入出力（その他の設定内） | 表示設定を移す。会話URL、タイトル、下書きは移さない |

**「前回の作業を復元しました」**は、保存済みの作業を自動で読み込んだ通知です。メニュー内だけに表示し、「通知を閉じる」は表示だけを消します。作業や保存データは変わりません。以前はこの表示自体が「新しい作業を開始」も兼ねていました。現在は通知だけになり、新しい作業を開始するUIは名前付きグループ保存に置き換えています。

グループ名は1〜100文字です。空白だけの名前は保存できません。同名の照合では前後の空白・文字幅・英字の大文字小文字を正規化します。保存に失敗した場合は現在のタブを維持します。結果が不明な場合は一覧を再表示してから再保存してください。復元は確認後に行い、現在の作業の保存に失敗したときは追加しません。「以前の作業」は従来どおり作業全体を保存して切り替えます。添付や生成中の処理はグループ保存にも含まれません。

下書き比較のUIはありません。既存の下書き・保護用バックアップは削除せず、保存・復元処理で保持します。

## 同じ会話を二重に開かないための動作

会話URLの追加、履歴クリック、一覧からの復元では、同じ会話の列があれば再利用します。Project/GPT経由のURL、クエリや末尾スラッシュが違っても同じ会話IDなら同一と判断します。退避・折りたたみ中の列も対象です。

名前付きグループの復元では、現在の列と入力を残し、不足する列だけを追加します。すでにある会話はページを再読み込みせず、現在の入力・幅を優先します。保存グループが表示対象としている列は表示・展開します。グループにない現在の列も残ります。現在の入力と異なる保存入力は保護用バックアップとして保持し、保存元グループも変更しません。

新規未送信チャットはURLが同じ `/` でも別の列です。グループ復元時は保存された列IDで区別するため、異なる新規チャットはまとめません。同じグループを繰り返し復元しても同じ列は増やしません。「＋ 新しいチャット」のダブルクリックは1回の作成として扱い、別々のクリックではそれぞれ新しいチャットを作成します。

## 保存と復元の範囲

同じブラウザプロファイルの拡張ローカル領域に、会話URL、表示名、順序、幅、折りたたみ・退避、選択、閉じた履歴、対応入力欄の未送信テキスト、設定を保存します。再読み込みやブラウザ再起動後に復元します。現在のページと使用中の作業を優先し、別タブと同じ保存済み作業を重複して開くことを避けます。

「未保存・再試行」が出た場合は内容を控えて再試行してください。添付ファイル、生成途中の処理、ページの実行状態は保存対象外です。折りたたみ・退避はiframeを保持するためメモリ削減を保証しません。端末間同期も保証しません。

実験的な拡張です。ChatGPTの画面構成や認証・埋め込み制限の変更で動作しなくなる場合があります。自動テストは認証済みChatGPTでの検証の代わりにはなりません。不具合時は「元画面」に戻すか拡張を無効にしてください。

### GPTページをタブで開く

サイドバーやページ内のGPTリンク（例：`https://chatgpt.com/g/g-h8l4uLHFQ-video-ai-by-invideo`）を通常クリックすると、分割表示内のタブで開きます。「履歴クリックを分割表示で開く」を有効にしてください。同じGPTがすでにある場合は、そのタブを表示して選択します。折りたたみ中・退避中も再利用します。

GPTの紹介・開始ページと、そのGPTで作成した個々の会話は別のタブとして扱います。GPTタブ内で会話が始まると会話URLに更新されるため、GPTリンクを再度開けば開始ページを別タブで開けます。通常の新規未送信チャット同士は統合しません。GPTページも名前付きタブグループの保存・追加復元に含まれます。

Ctrl・Command・AltクリックやChatGPTの操作メニューは従来の動作を維持します。GPT内の専用「新しいチャット」コマンドはChatGPT側で処理します。別ウィンドウへの分離は送信済み会話が対象です。この対応はGPTリンク向けで、デスクトップのSkills管理画面とは別です。


GPT対応は特定のGPT専用ではありません。`/g/g-<英数字ID>` と `/g/g-<英数字ID>-<名前>` を対象とし、名前が変わっても同じIDなら既存タブを利用します。クエリ・フラグメント・末尾の `/` は正規化します。クエリの値は保持しないため、URLで指定された初期プロンプトやモデル等の追加動作は再現しません。`/g/.../c/<会話ID>` は個別の会話として扱います。Skills管理、Plugins、GPT探索・編集、設定、ライブラリ、共有ページなどを一律にタブ化する対応ではありません。


退避専用ボタンは撤去し、通常の縮小操作を `_` による折りたたみに統一しました。旧版で退避したタブは消去せず「退避中」として一覧に残り、「戻す」で表示できます。旧版の保存済みグループ内にある退避タブも復元後の一覧から戻せます。別ウィンドウへ開いた際の元タブも、今後は折りたたんで保持します。


### 左側メニューの構成

分割表示中は左端の「メニュー」「新しいチャット」「左一覧を隠す／表示」「元画面／分割へ」はメニューを閉じても使えます。メニュー内はタブ一覧、タブグループ、表示設定の順です。選択中のタブは背景色と状態表示で確認でき、長いタイトルは省略表示し、フォーカス可能なタブ名ボタンとツールチップで確認できます。タブグループはメニューを開いたときに一覧を読み込み、名前付き保存と既存グループの復元を同じ区画から行えます。列幅・等分・左一覧幅・その他の設定は「表示設定」を開いて変更します。表示設定はTabで選択しEnterまたはSpaceで開閉できます。操作バーは左端40px、メニューと左一覧はその右に配置し、会話列も右端に追従します。設定済みの左一覧幅は変更しません。狭い幅では左端の4操作を各1クリックで使えます。元画面では操作バーを隠し、ヘッダー内の「分割へ」だけを表示します。分割表示では上部の操作帯を使わず、会話列は画面上端から表示します。左一覧非表示時の会話列は左端40pxから始まります。以前の浮動位置は表示に使用しません。


タブ名を押すと選択・復元し、右端の「−／□」で折りたたみ・復元します。タブグループの保存フォームと説明は「グループを保存」を押すと表示します（初期名は端末の当日の日付 `YYYY-MM-DD`）。キャンセルは保存せず閉じます。URLから追加・閉じた履歴・旧退避タブの復元は引き続き利用できます。


v0.9.0ではタブ行を38pxに詰め、画面上の状態文字を省略しました。選択色と右端ボタンで状態を示し、読み上げ用の状態説明と操作名は保持します。

元画面では「分割へ」ボタンだけをChatGPTのヘッダー内の通常配置で表示します。ヘッダーがない画面ではmain、次にbodyの先頭に配置し、スクロール中も上端に保持します。画面に重ねる固定バーや高さ変更は行いません。列と未送信入力は保持されます。

v0.9.2では分割メニューがChatGPT側のサイドバーの背後へ隠れる問題を修正しています。元画面では引き続き復帰ボタンのみ表示します。
