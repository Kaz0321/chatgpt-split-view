# ChatGPT Split View

ChatGPTの複数の会話を横に並べて使うChrome拡張です。会話を見比べながら作業し、タブを折りたたんだり、構成を名前付きグループとして保存したりできます。OpenAIの公式製品ではありません。

**バージョン: 1.0.16** · [更新履歴](docs/changelog.md) · [リリース検証状況](docs/release-1.0.0.md)

## インストールと更新

1. リポジトリのソースZIPを展開します。
2. Chromeで `chrome://extensions` を開き、「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から、展開した中の **extension** フォルダーを選びます。配布用ZIPの場合は、`manifest.json` が直下にあるフォルダーを選びます。
4. ChatGPTを開き、拡張のポップアップ、または画面の「分割を開始」から使い始めます。

更新時は、未送信の文章を控えてから、現在読み込んでいる同じフォルダーを更新してください。拡張管理画面で拡張を再読み込みし、ChatGPTのページも更新します。拡張の削除や別フォルダーへの変更は、保存データが引き継がれない原因になります。

## 基本の操作

左端の縦バーは、上から次の順番です。アイコンにカーソルを合わせると操作名が表示されます。

| 操作 | できること |
| --- | --- |
| タブ管理 | 現在の全タブ、閉じた履歴、保存済みグループを表示 |
| 左一覧の表示切替 | 左側の一覧を隠す／表示する |
| 新しいチャット | 右端に独立した新規チャットを追加 |
| 全部縮小（⊟） | 新しいチャットの直下。表示中の分割タブをまとめて折りたたむ |
| メイン（元画面） | 親ページのChatGPTへ切替。「メイン · 分割へ」で戻る |
| 下端の歯車 | オプション画面を開く |

元画面に切り替えても、分割側のタブと入力は保持されます。元画面では既存の復帰ボタンに「メイン · 分割へ」と表示します。左バーにも「メイン」の文字、タブ管理には「メイン（元画面）を表示」があります。メインは親ページを指し、選択中の分割タブとは別です。同じ会話URLの列や新規チャットをメイン扱いすることはありません。

分割中にサイドバーのプロジェクトを展開し、「プロジェクト名 で新しいチャット」を押すと、そのプロジェクトの新規入力を独立したタブで開きます。同じプロジェクトでも新規入力は別々に保持します。対象プロジェクトを判定できないボタンや修飾キー付きクリックはChatGPTの元動作を残します。左端バーの「新しいチャット」は通常の新規チャットです。

## タブを操作する

ここでいうタブは拡張内の会話列です。Chromeのタブそのものではありません。

| タブ上部の操作 | 動作 |
| --- | --- |
| `_` | タブを細い背表紙に折りたたむ。ページと入力を保持 |
| 背表紙の `□` | 元の幅に戻す。タブ管理の一覧からも復元可能 |
| リンクアイコン | そのタブの会話URLをコピー |
| `…` | 判定できる場合にChatGPTの会話メニューを開く（実験的） |
| `↻` | 確認後、そのタブだけ再読み込み |
| `↗` | 送信済み会話を別ウィンドウで開き、元のタブを折りたたむ |
| `×` | タブを閉じる。ChatGPTの会話自体は削除しない |
| 6点ハンドル（⠿） | 通常・折りたたみ中ともドラッグで並べ替え。フォーカスしてAlt＋左右でも移動 |

列の境界をドラッグすると幅を調整できます。画面に収まらない列には横スクロールで移動します。長いタブ名は省略表示し、ツールチップで確認できます。各ボタンはTabで選択し、EnterまたはSpaceで操作できます。

URLコピーは現在のURLを優先します。読めない場合は保存済みURLと通知し、コピーできない場合は選択用ダイアログを表示します。未送信の新規チャットに固有URLはありません。GPT開始ページではGPTのURLを取得します。

`…` は対象の会話メニューを特定できない場合、通知だけを表示します。アカウントや回答単位のメニューは対象外です。**実ChatGPTでの動作確認は未完了です。**

## タブ管理とグループ

一覧には表示中・折りたたみ中・旧版で退避したタブが含まれます。タブ名を押すと選択・復元し、右端のボタンで折りたたみ・復元できます。選択中は背景色で区別します。

- **URLから追加**: 会話またはGPTのURLを指定して開きます。同じ会話が開いていれば既存のタブへ移動します。
- **閉じた履歴**: この作業で閉じたタブを検索して再度開きます。ChatGPTの全履歴ではありません。履歴から開いた場合、未送信入力は戻りません。
- **グループを保存**: 現在の構成を名前付きでコピー保存します。初期名は当日の日付です。同名は連番を付け、上書きしません。キャンセルは変更を保存しません。
- **保存済みグループを復元**: 現在の作業を保護してから、不足するタブを追加します。既存の会話と入力を優先し、同じ会話は二重に開きません。

新規未送信チャットはURLが同じでも別タブとして扱います。同じグループの繰り返し復元では、保存時のタブIDを使って重複を防ぎます。

旧データの「以前の作業」はグループと異なり、現在の作業を保存してから作業全体を切り替えます。復元前の確認内容を読んで操作してください。

「前回の作業を復元しました」は自動復元の通知です。「通知を閉じる」で表示だけを消せます。保存データには影響しません。

## 表示設定

左端下部の歯車からオプションを開きます。列幅・標準幅・等幅・左一覧幅とロック・本文左右余白・履歴リンクの開き方などを変更し、**変更を保存**を押してください。「変更を取り消す」で未保存の編集を戻せます。

設定JSONの書き出し・読み込みは表示設定だけが対象です。会話・タイトル・下書き・保存グループのバックアップにはなりません。

## 保存されるものと制限

同じChromeプロファイルの拡張ストレージに、タブのURL・表示名・順番・幅・折りたたみ状態、保存グループ、対応する入力欄の未送信テキストなどを保存します。添付ファイル、生成途中の処理、ページ全体の状態は復元できません。端末間の同期も保証しません。

閉じた直後の「元に戻す」は30秒以内の対応テキスト復元です。添付や生成中の状態は対象外です。折りたたみはページを保持するため、メモリ削減を保証する機能ではありません。

ChatGPTの画面変更や埋め込み制限により動かなくなる場合があります。表示や切替に問題がある場合は、未送信文を控え、拡張を無効にして通常のChatGPTを利用できます。

v1.0.0は自動テストと配布物の検査を実施していますが、今回の実Chromeでの画面操作・狭幅表示・認証を含む受入確認は未完了です。[確認済み／未確認の一覧](docs/release-1.0.0.md)を参照してください。

### 本体の左一覧がホバー表示される場合

ChatGPT本体の一覧が閉じている間は、アイコン列だけの幅に縮めます。本体側の一時表示・固定・解除に合わせて会話列の位置が変わります。拡張の縦バー2番目は本体の左列全体を非表示／再表示するボタンです。再表示しても本体の固定状態は変更しません。保存した左一覧の幅設定は保持します。

### レビュー・分割画面で列を広げる

列の上端にある **↔** を押すと、その列だけを一時的に広げます。もう一度押すと元の幅へ戻ります。狭い画面では横スクロールで閲覧します。他の列の幅・保存済みの幅設定・未送信入力は変更しません。

ChatGPT本体が右側の分割パネルを開いたことを検出できる場合は、自動で広げ、閉じると元の幅へ戻します。自動検出は本体の表示状態属性に対応した画面に限られます。Canvas・レビュー・ファイル表示の全種類での実画面検証は未完了です。広がらない画面では **↔** を使い、閉じた後にも **↔** で戻してください。

- 一時幅は利用できる横幅を基準に、通常1100〜1800px。元の列がそれ以上なら縮めません。
- 拡張中も列の右端をドラッグして320〜2400pxに調整できます。この調整は一時的で、通常の保存幅には反映しません。
- 等分表示でも対象列だけが広がります。等分の設定と他列の幅は維持します。
- 自動拡張を **↔** で解除すると、そのパネルを閉じて再び開くまで自動で広げ直しません。
- ページ移動・再読み込みでは一時幅を解除します。グループには通常の幅を保存します。

### まとめて縮小・縮小タブを閉じる

左端の操作バーで「新しいチャット」の直下にある **全部縮小（⊟）** を押すと、表示中のタブをすべて折りたたみます。ページ・未送信入力・元の幅を保持するため、各タブを個別に復元できます。既に非表示の旧退避タブは変更しません。

縮小タブの上端は復元ボタン、下端の **×** は閉じるボタンです。閉じる動作は通常タブと同じで、ページを破棄します。誤って閉じた場合は30秒以内の「閉じた列を元に戻す」で可能な範囲のテキストを復元できます。添付や生成中の状態の完全復元は保証しません。

### 添付操作と左側の境界線

ファイルは添付したい会話の中へドロップするか、その会話の添付ボタンから選択してください。添付画面が隣接タブに残る問題は未解決です。v1.0.8の補助通知は追加検証で有効性を確認できず、v1.0.9で撤回しました。添付ファイルの転送・削除や会話の再読み込みは行いません。

左メニューと会話タブの境界には細い縦線を表示します。左一覧の表示切替や幅変更に追従し、幅を固定しても表示されます。

### 会話名と表示名

ChatGPTの履歴に表示される会話名を、約1.5秒ごとに拡張の列・折りたたみタブ・左メニューのタブ一覧へ同期します。会話IDで対応付けるため、未送信の新規チャット同士は同期しません。履歴がDOMに存在しない会話や、名前を確定できない場合は現在の表示を保持します。

列のタイトル欄で名前を入力して確定すると、ChatGPT本体の会話名を変更します（実験的）。対象の同じiframe内で本体の「名前を変更」画面を操作し、「保存」後に会話ID・履歴名を照合します。iframeの再作成・再読み込みや独自の非公開APIは使いません。変更中は同じ会話への重複操作を止め、入力欄を一時的に読み取り専用にします。

対応対象は通常の保存済み `/c/…` と、確認済み形式の `/g/g-p-…/c/…` プロジェクト会話です。新規入力・分岐の仮URL・ローカルスレッド・GPT開始ページ・一般のGPT固有会話・未確認のプロジェクトURL形式は変更しません。

対応していない画面、認証・遷移中、メニューや保存結果を確認できない場合は通知し、ローカル表示名への変更で成功を装いません。保存結果が不明な場合は自動再試行せず、本体の会話名を確認してください。本体画面を途中で操作した場合も中断します。開いた本体メニューや入力画面が残ることがあります。

旧版のローカル表示名は自動で本体へ送信しません。明示的に編集して変更が確認できた列だけ自動同期へ戻します。他の列のローカル表示名と編集中の文字は保持します。空欄で確定すると、名前を送信せず会話名への自動同期に戻ります。

実ChatGPTでは名前変更メニュー・入力画面を読み取り確認し、保存せずキャンセルしました。インストール後の改名保存・再読み込み後の永続化は未検証です。自動試験は合成DOMによるもので、サービス側保存の成功を保証しません。

既に読み込んだ別ページの古い名前は反映しません。同じページで名前が変わった場合は、以前使った名前への改名も反映します。複数ページで競合する場合は最後に観測した変更を採用します。同じ確認周期ではメイン、次に列の順で観測します。DOMだけでは実改名と遅れたサーバー応答を区別できないため、応答の遅延による巻き戻しを完全には防げません。

### 元の列を残して会話を分岐する

1. 保存済み会話の列上部で「分岐準備」を押します。元のすぐ右に「分岐準備」の列を開きます。元列の未送信入力・添付・生成中の画面は移動もコピーもしません。
2. **準備列**で分岐したいメッセージの「…」から、ChatGPT本体の「Branch in new chat」などの分岐操作を選びます。元列で対応する分岐項目を選んだ場合も、まず準備列を開くので、そこで分岐を選び直してください。
3. 準備列が別IDの会話URLへ遷移し、本体の分岐元表示で元会話との関係を確認した場合、その列を分岐先として確定し、元の隣に配置します。別ブラウザータブで開いた場合や検出されない場合は、準備列上部の「分岐先URL」から本体で作成したURLを指定します。URL指定は別会話を並べる操作であり、分岐を作成する操作ではありません。

クリック監視は別の操作・Esc・認証画面への遷移・30秒経過で解除します。クリック監視の有無にかかわらず、現在の会話内にある分岐アイコン・元会話へのリンク・「からの続き」の表示を照合して確認します。準備列を×で閉じればキャンセルできます。元列が別会話へ移動した場合は自動確定しません。既存の分岐先は再利用して並べ替え、準備列は入力保護のため残します。不要な準備列は手動で閉じてください。

準備列も保存できますが、クリック監視の状態は復元しません。元と同じURLの準備列には「分岐未作成」を常時表示します。添付・生成状態の保存復元には従来と同じ制限があります。未送信の新規チャットやGPT開始ページは分岐準備の対象外です。メインから直接の分岐は捕捉しないので、会話を分割列で開いてから使ってください。

実Chromeで「会話を分岐する」→「新しいチャットに分岐」と、同じiframe内の `/c/local-chatgpt%3A…` 仮URLへの遷移を確認しました。仮URL対応の修正版を読み込んだ一連操作は未確認です。仮URLの分岐は本体で保存されるまで再読み込み・終了後の復元を保証できません。内部APIは利用せず、現在の会話IDと本体の分岐元表示で判定します。クリック直後でも、元会話との関係を確認できないURLは分岐先として自動採用しません。

手動URL取込でも元列の現在URLを照合します。元が別会話・新規ルート・認証画面に変わった場合や読み取れない場合は中止します。多列の確認をキャンセルした場合や上限で追加できない場合は成功表示を出しません。

仮URLからの分岐準備は停止します。手動で仮URLを取り込む場合も、同じ会話の既存列を再利用できる場合に限り、新しいiframeには読み込みません。保存済みの通常URLになってから準備・取込してください。

### v1.0.16 の分岐URL確認

自動確定の対応範囲は、確認済みの日本語UIに限ります。現在の会話内にある分岐アイコン、元会話へのリンク、文字列「からの続き」を照合します。英語の「Branch in new chat」を認識しても、他言語や本体DOMの変更でこの証拠を確認できなければ自動確定しません。その場合は、本体で作成した分岐先のURLを「分岐先URL」から手動で取り込んでください。仮URLを別の列へ新規に読み込むことはできないため、保存済みURLになってから取り込むか、すでに表示中の同じ仮URLの列を再利用してください。

iframe の `src` は最初に開いた元URLのままでも、ChatGPTの画面内遷移後の `location.href` は別の会話になります。実際のURLと会話IDで判定し、URL表示を合わせるためだけの再読み込みはしません。分岐確認後は新URLをワークスペースに保存し、仮URLが保存済みURLへ変わった場合も定期確認で追従します。

準備列は分岐そのものではありません。「会話を分岐する」は本体のサブメニューであり、「新しいチャットに分岐」を選ぶまで作成しません。「Work モードに分岐」はこの機能の対象外です。仮URLの会話を再読み込み・終了後に復元できる保証はありません。新しいコードの適用のために、未保存の分岐画面を再読み込みしないでください。
