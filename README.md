# ChatGPT Split View

ChatGPT の会話を横一列の列として並べる、非公式の Chrome 拡張機能です。親の履歴ペインを残し、列幅・等分・並べ替えを操作できます。

**v0.5.0 は検証候補です。Node 69 件と合成 Chromium 画面で確認済みですが、実拡張の読み込み、本物の action popup、ログイン済み ChatGPT と実添付アップロードは未検証です。** OpenAI 公式製品ではなく、ChatGPT の画面変更で動作しなくなる可能性があります。

## 導入

管理ポリシー上許可された検証用 Chrome を使ってください。制限された環境の設定を回避する手順ではありません。

1. このリポジトリのソース ZIP を取得して展開するか、clone します。ビルドや npm install は不要です。
2. Chrome の拡張管理画面でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」から **リポジトリ内の `extension/` フォルダー**を選びます。リポジトリ直下ではありません。
   - 配布用 `chatgpt-split-view-v0.5.0-candidate.zip` を使う場合は、展開後の `manifest.json` があるフォルダーを選びます。この配布ZIPには `extension/` の一段上の構造を入れません。
3. 必要なら拡張アイコンをツールバーにピン留めします。
4. ChatGPT を開いて、拡張アイコンを押し「横並びを開始」を選びます。既に開いていたページには、未送信入力がないことを確認して再読み込みが必要な場合があります。

一般的な読み込みと更新の手順は [Chrome 公式の拡張チュートリアル](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked) を参照してください。manifest の最低バージョン指定は Chrome 114 ですが、その全バージョンの互換性を検証したという意味ではありません。

## 使い方

| 場所 | 操作 |
|---|---|
| 拡張アイコンの popup | 開始／終了、右端へ追加、列幅、等分、隠した列の復帰 |
| 親の会話履歴 | 会話を常に右端へ追加。右端が空列ならそこへ表示 |
| 列左端の `⠿` | ドラッグで並べ替え。フォーカスして Alt＋←／→でも移動 |
| 列の「↻ 更新」 | その列だけ再読み込み。毎回確認し、未送信入力・添付が失われる可能性を通知 |
| 列右端の「❌」 | 列を非表示にする。会話は削除せず、popup から復帰可能 |
| popup の「その他の設定」 | 親／子ペイン表示、履歴クリック、設定 JSON の入出力など |

ページ上部に常設ツールバーはありません。等分は列の最小幅 320px を守り、多数の列は横スクロールします。最大幅は親画面から検出し、検出不能時の 920px は暫定値です。

更新は ChatGPT にその会話を読み直させる操作です。**端末間の同期を実装・保証する機能ではありません。** 設定も端末ローカルです。添付ファイルのドラッグを列並べ替えとして扱わない設計ですが、実 ChatGPT でのアップロード先確認は残っています。

## 更新と戻し方

- 旧版フォルダーを退避し、検証用フォルダーの実行ファイルを新版に置き換えます。ソース取得時の読み込み対象は `extension/` です。拡張管理画面で拡張を再読み込みし、未送信入力を保護してから ChatGPT ページも再読み込みします。
- 以前リポジトリ直下から読み込んでいた場合は、今回の `extension/` を選び直す必要があります。別フォルダーから読み込むと拡張 ID が変わる可能性があります。設定の JSON 入出力で移せるのは表示設定だけで、会話 URL・タイトル・下書きは移しません。
- 不具合時は popup で元画面へ戻り、拡張を無効にしてください。旧版へ戻す際も未送信内容を先に保護してください。
- 「❌」は文書を保持するので、メモリを即時解放する操作ではありません。ページを閉じたり再読み込みすると未送信内容を失う場合があります。

## 権限と保存内容

`storage` 権限と `https://chatgpt.com/*` 上の content script を使用します。ChatGPT 画面の読み取り・変更が可能な拡張です。「権限が storage だけだから画面を読めない」という意味ではありません。

表示設定は拡張のローカル保存領域、列 URL・タイトル・順序などは ChatGPT タブの sessionStorage に保存します。独自サーバーへの送信・分析 SDK はありませんが、iframe の ChatGPT 自体は通常どおりネットワークを利用します。[保存とプライバシーの詳細](docs/privacy.md) を確認してください。

## 検証と開発

```sh
npm run verify
python3 scripts/package.py
python3 scripts/package.py --check
```

ソース検証は Node.js 24、配布 ZIP 作成は Python 3 の標準ライブラリだけを使用します。依存パッケージのインストールは不要です。ZIP は `dist/` に生成され、Git には含めません。
